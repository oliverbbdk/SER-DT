# Kildestatus

Gruppeprojektet er en selvstændig kopi af den udgivne SE RØDT-kode, hentet 4. november 2026.

Webkildens commit: `c952216f6ca6864be9167ca74109bf05ded4172b`.

Den nye Git-historik starter ved denne gruppeaflevering. Den indeholder ikke den oprindelige hostinghistorik.
Den oprindelige hostingopsætning og dens login-/adgangsoplysninger er ikke en del af gruppeprojektet.
Den eksisterende hjemmeside er ikke ændret af kopieringen og er fortsat privat efter den seneste adgangskontrol.

Opgavegrundlaget er gruppens eventkoncept, moodboard og Figma-filoversigt.
Designreferencerne ligger under `skills/se-rodt-design/references/`.
Den private gruppekontrakt er ikke en del af webprojektet.

HTML, CSS, JavaScript, lokale assets, fontlicenser, datakilder, AI-skills og portable byggescripts følger med.
Filmtrailers og eksterne forhåndsvisninger tilhører deres udgivere og hentes via officielle YouTube-kilder.
